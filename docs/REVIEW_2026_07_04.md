## 2. Review findings (Tasks 12–14)

### Security (Task 12)

**Fixed**
1. **Compose images unpinned** — `docker-compose.yml` pinned postgres/nginx by
   tag and `certbot/certbot` by nothing (implicit `:latest`). Digest-pinned all
   four; extended the refresh script. `e740c06`.
2. **TLS session-resumption footgun (latent).** The two `InsecureSkipVerify` +
   `VerifyPeerCertificate` federation clients are safe today (nil
   `ClientSessionCache` → no client resumption → custom identity check runs every
   connection), but a future cache would silently bypass verification on resumed
   sessions. Documented the invariant + added a regression guard test. `b9b2e84`.

**Reviewed sound (no change):** envelope AEAD (XChaCha20-Poly1305, fresh random
24-byte nonces), master-key wrapping, argon2id params (t=3/64 MiB/p=2),
constant-time compares on signed URLs + upload tokens, no secret logging,
`InsecureSkipVerify` only ever paired with real custom verification, SQL-injection
surface (parameterized; the two `Sprintf`-DDL sites use regex-validated
partition names). Detail: `docs/.m7.1-review-security.md`.

### Logic & concurrency (Task 13)

**Fixed** (`48345e6`)
1. **`pin_db_test.go` false-PASS** — swallowed Begin/Commit/List/Unpin errors let
   a failed final list satisfy `len()==0`; all errors now checked.
2. **`novactl` setup prompts** now surface `scanner.Err()` instead of masking a
   read error as "stdin closed".

**Reviewed sound:** the retention Maintainer runs partition create-ahead
unconditionally of `IntegrityAudit.Enabled` (only the scheduler is feature-gated);
empty `source_nebula_addr` is guarded at the agent (no capability advertised) AND
every selection query (`IS NOT NULL AND <> ''`); the below-floor sweep adds no new
concurrency (single-leader loop, atomic single-statement queries, authority-based
demote guard). `-race` clean on bandwidth/envelope/admission. **Minor recorded:**
partition provisioning is coupled to `backend != nil && ks != nil` — fine for real
coordinators (both always present) but a cleaner design would decouple it. Detail:
`docs/.m7.1-review-logic.md`.

### Performance (Task 14)

**Verdict: no hot-path regression.** The only new query surface (the below-floor
sweep) runs at 60 s tick cadence / scrape time, not the request path. The demote
reuses the bench-proven `CountDrainPendingCIDs` hash-aggregate shape. Added a
`TestExplainPlans` case asserting the requeue victim selection drives from
`nodes_below_floor_idx` rather than scanning `pin_assignments` at scale
(`603d62a`). `make bench-corpus-explain` green. The hours-long 9.8M-row
`make bench-corpus` p95 gate was not re-run — no query was added to its hot-path
profile set, so its p95s are unaffected (re-run is a Task 17 option). Detail:
`docs/.m7.1-review-perf.md`.
