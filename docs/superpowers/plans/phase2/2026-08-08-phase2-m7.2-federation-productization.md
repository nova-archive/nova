# P2-M7.2 Federation Productization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Nova's working federation protocol into a deployable product — one tested path from a running standalone operator to a registered, serving donor, with no manual PKI choreography and no artifact that contradicts another.

**Architecture:** A packaged `nova-admin` container owns issuance authority and runs `federation init` / `node invite`; a separate `nova-doctor` container shares the coordinator's network namespace to observe the overlay; a static Compose-policy gate proves CA keys can never reach a long-running service. The canonical donor deployment definition moves to `internal/deploy/templates/` and generates both the invite bundle and the checked-in `deploy/donor/*`. The coordinator's federation startup changes from bind-or-die to bind-or-degrade with a bounded wait, breaking the sidecar deadlock.

**Tech Stack:** Go 1.26 (stdlib `crypto/x509`, `text/template`, `embed`), Docker Compose v2, Nebula, Kubo, chi router, Prometheus client, bash for CI gates.

**Design spec:** `docs/superpowers/specs/phase2/2026-08-08-phase2-m7.2-federation-productization-design.md`

## Global Constraints

- **Port vocabulary is fixed:** `4242/udp` Nebula lighthouse; `9443/tcp` coordinator federation mTLS (overlay only); `9555/tcp` donor read-source mTLS (overlay only). `8443` means only the operator's public nginx HTTPS port. Every artifact must agree.
- **Canonical donor paths:** `/etc/nova` for public/configuration material, `/run/secrets` for private keys, `storage_dir: /var/lib/nova-node/data`.
- **CA private keys** (Nova federation CA, Nebula CA) live only in the `nova-fedpki` volume, mounted only into `nova-admin`. Never into `coordinator`, `nebula`, `nova-doctor`, or a donor bundle.
- **No mutable image tags** in any operational template or generated artifact. Digests only.
- **No migration.** `migrations-frozen` must stay green.
- **`donor-deps-boundary` must stay green.** Run `make node-deps-check` after any change under `internal/` that the donor graph might reach.
- **The Kubo swarm key is never rotated during adoption.**
- **`gofmt` only files you touched** (go.mod is 1.26.2, host toolchain 1.26.3).
- **Every task ends with `make test` green** unless the task text says otherwise.

```go
// internal/config/federation_wait.go
package config

import (
	"context"
	"fmt"
	"time"
)

// WaitForInterfaceAddr polls until hostPort's host is an address of iface, the
// timeout elapses, or ctx is done. It exists because the federation listener
// must not fail the process when the Nebula sidecar has not yet created the
// overlay interface (P2-M7.2 D-M7.2-8b): the sidecar shares the coordinator's
// network namespace, so the coordinator must be running first.
func WaitForInterfaceAddr(ctx context.Context, iface, hostPort string, timeout, poll time.Duration) error {
	f := Federation{ListenAddr: hostPort, NebulaInterface: iface}
	deadline := time.Now().Add(timeout)
	var last error
	for {
		if last = f.checkListenOnInterface(); last == nil {
			return nil
		}
		if err := ctx.Err(); err != nil {
			return fmt.Errorf("waiting for %s on %s: %w", hostPort, iface, err)
		}
		if !time.Now().Before(deadline) {
			return fmt.Errorf("timed out after %s waiting for %s on %s: %w", timeout, hostPort, iface, last)
		}
		select {
		case <-ctx.Done():
			return fmt.Errorf("waiting for %s on %s: %w", hostPort, iface, ctx.Err())
		case <-time.After(poll):
		}
	}
}

// InterfaceWaitTimeout is how long boot waits for nebula_interface to carry
// listen_addr. Default 120s; 0 restores pre-M7.2 fail-fast behaviour.
func (f Federation) InterfaceWaitTimeout() time.Duration {
	if f.InterfaceWaitSeconds < 0 {
		return 0
	}
	if f.InterfaceWaitSeconds == 0 {
		return DefaultInterfaceWaitSeconds * time.Second
	}
	return time.Duration(f.InterfaceWaitSeconds) * time.Second
}
```

```go
// cmd/coordinator/federation_readiness.go
package main

import (
	"encoding/json"
	"net/http"
	"sync"
	"time"
)

// federationReadiness is the coordinator-authoritative answer to "is the
// federation listener up, and on what?" (P2-M7.2 D-M7.2-8c). It is served on
// the operator-only metrics listener, never the public vhost, because the
// overlay address is topology the public surface must not disclose.
type federationReadiness struct {
	mu         sync.RWMutex
	ready      bool
	iface      string
	boundAddr  string
	waitingFor string
	since      time.Time
	onChange   func(bool)
}

func newFederationReadiness(iface, wantAddr string) *federationReadiness {
	return &federationReadiness{iface: iface, waitingFor: iface, boundAddr: "", since: time.Now().UTC()}
}

// SetObserver wires the nova_federation_listener_ready gauge (nil-safe, the
// same seam pattern the other P2-M7 metric families use).
func (f *federationReadiness) SetObserver(fn func(bool)) { f.onChange = fn }

func (f *federationReadiness) Set(ready bool) {
	f.mu.Lock()
	f.ready, f.since = ready, time.Now().UTC()
	f.mu.Unlock()
	if f.onChange != nil {
		f.onChange(ready)
	}
}

func (f *federationReadiness) SetBound(addr, iface string) {
	f.mu.Lock()
	f.ready, f.boundAddr, f.iface, f.waitingFor, f.since = true, addr, iface, "", time.Now().UTC()
	f.mu.Unlock()
	if f.onChange != nil {
		f.onChange(true)
	}
}

func (f *federationReadiness) Handler() http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		f.mu.RLock()
		body := map[string]any{"federation": map[string]any{
			"ready":       f.ready,
			"iface":       f.iface,
			"bound_addr":  f.boundAddr,
			"waiting_for": f.waitingFor,
			"since":       f.since.Format(time.RFC3339),
		}}
		ready := f.ready
		f.mu.RUnlock()

		w.Header().Set("Content-Type", "application/json")
		w.Header().Set("Cache-Control", "no-store")
		if !ready {
			w.WriteHeader(http.StatusServiceUnavailable)
		}
		_ = json.NewEncoder(w).Encode(body)
	}
}
```
