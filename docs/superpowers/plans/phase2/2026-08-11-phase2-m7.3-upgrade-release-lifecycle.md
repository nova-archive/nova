# P2-M7.3 — Upgrade & release lifecycle: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A day-2 contract — releases built once and promoted by digest under an
out-of-band trust anchor, compatibility bound to signed evidence, composable
migration obligations, honest version reporting with explicit trust labels, and a
coordinator that requires **no coordinated donor upgrade**.

**Architecture:** Checked-in **intent** (decisions, reviewed pre-build) → build
candidate **once** → gates on those exact digests → signed **lock** (facts +
evidence) → approval → promote OCI refs and read back → Git product tag →
immutable release. Trust starts at the host's Cosign installation plus an
out-of-band signer policy, never at the material being verified. At runtime a
binary knows only its embedded build info and generated catalog; a target lock
arrives as an operator-supplied verified file. Donor-reported metadata is
`reported_*` and never authorizes; the interop contract stays
`supported_protocols` + `capabilities`.

**Tech Stack:** Go 1.26; `golang.org/x/mod/semver`,
`github.com/distribution/reference`, `github.com/opencontainers/go-digest` and
`github.com/opencontainers/image-spec` (all four already indirect dependencies —
this promotes them to direct, adding no new module provenance, though it does
compile previously indirect packages into shipped tools); goose + sqlc; Postgres
advisory locks; Cosign; Docker Buildx; Compose v2; GitHub Actions.

## Global Constraints

- **T1.22** — no telemetry, phone-home or auto-update in coordinator or donor
  binaries. **T1.24** — `audit_log` append-only; privileged actions logged.
- **The interop contract is `supported_protocols` + `capabilities`**
  (`FEDERATION_PROTOCOL.md:545-547`). Version classes are policy and never gate
  protocol access, placement, durability counting, trust, drain or eviction.
- **`draining_at` is operator-controlled.** No heartbeat or automatic lifecycle
  path may set it.
- **`selected_protocol` is the coordinator's negotiated outcome**
  (`handlers.go:115,130`). A donor advertisement never overwrites it.
- **Support window: two immediate donor predecessors OR six months since
  `support_epoch`, whichever leaves the artifact supported longer.**
- **Baseline = commit `143c459`, schema 18, locally built images.** The remote
  tag namespace holds only two lightweight `v0.2.0-beta.1+…` refs; do not cite
  any milestone tag as published.
- **Migrations 0001–0018 never edited**; `MANIFEST.sha256` **appended**, never
  regenerated. Exactly one new migration: **0019**.
- **No `fed/v2` bump** — optional fields only. No `DisallowUnknownFields` on the
  wire path; release-metadata loaders are not the wire path and should have it.
- **No unpinned mutable refs.** (`certbot/certbot:latest@sha256:…` is correctly
  pinned; the rule is about mutability, not the word `latest`.)
- **The material being verified is never its own trust anchor.**
- **Git tags are created only by the release state machine** (Task 26), only
  after a successful OCI read-back. No other task creates a product tag.
- Every gate proven to fail when broken, using a **committed fixture** where
  stated. `gofmt -w` **only the exact files you touched** — list them, never a
  directory.

```sql
-- +goose Up
-- Upgrade history as a RUN with PHASES. One flat row cannot describe an
-- interrupted upgrade, which is when the record matters most.
CREATE TABLE upgrade_runs (
    id uuid PRIMARY KEY,
    from_release text NOT NULL DEFAULT '', to_release text NOT NULL,
    from_schema bigint NOT NULL, to_schema bigint NOT NULL,
    release_lock_digest text NOT NULL DEFAULT '',
    expected_artifacts jsonb NOT NULL DEFAULT '{}'::jsonb,
    obligations jsonb NOT NULL DEFAULT '{}'::jsonb,
    config_fingerprint_before text NOT NULL DEFAULT '',
    config_fingerprint_after  text NOT NULL DEFAULT '',
    state text NOT NULL CHECK (state IN ('started','passed','failed','aborted','skipped','interrupted')),
    actor text NOT NULL DEFAULT '',
    started_at timestamptz NOT NULL DEFAULT now(), completed_at timestamptz
);

-- Upgrade history is evidence (T1.24). ON DELETE CASCADE would let deleting a
-- run erase its own events, so the FK RESTRICTs; removing history is a
-- privileged action and belongs in audit_log.
-- (run_id, sequence) is the replay key. The journal is replayed into this table
-- after 0019 applies, and a crash halfway through backfill would otherwise
-- duplicate every event already written on restart. A bigserial ID alone cannot
-- express "this journal event is already here".
CREATE TABLE upgrade_events (
    id bigserial PRIMARY KEY,
    run_id uuid NOT NULL REFERENCES upgrade_runs(id) ON DELETE RESTRICT,
    sequence bigint NOT NULL,
    phase text NOT NULL CHECK (phase IN ('preflight','apply','verify','rollback')),
    state text NOT NULL CHECK (state IN ('started','passed','failed','aborted','skipped','interrupted')),
    detail jsonb NOT NULL DEFAULT '{}'::jsonb,
    recorded_at timestamptz NOT NULL DEFAULT now(),
    UNIQUE (run_id, sequence)
);
CREATE INDEX upgrade_runs_started_at_idx ON upgrade_runs (started_at DESC);
CREATE INDEX upgrade_events_run_idx      ON upgrade_events (run_id, recorded_at);

-- IDENTITY CLAIMS: census-only. These never gate protocol access, placement,
-- durability, trust, drain or eviction; a mismatch against the operator's
-- expected_* value is a supply-chain warning. Image digest and bundle-lock
-- digest are separate relations: a donor can match one and not the other.
ALTER TABLE nodes ADD COLUMN reported_client_version     text;
ALTER TABLE nodes ADD COLUMN reported_image_digest       text;
ALTER TABLE nodes ADD COLUMN reported_bundle_lock_digest text;

-- CAPABILITY ADVERTISEMENTS: these DO gate routing (a donor that cannot serve
-- reads must not be sent read work) — a routing decision, not a security
-- authorization. effective_capabilities is the SINGLE operational source read by
-- federation.sql, replication.sql, storage_state.sql and possession.sql; the
-- reported_* raw claim is kept only for the census. Donor-advertised protocols
-- are separate from selected_protocol, which is the coordinator's negotiated
-- outcome (handlers.go:115,130), not a donor claim.
ALTER TABLE nodes ADD COLUMN effective_capabilities text[];
ALTER TABLE nodes ADD COLUMN reported_protocols     text[];
UPDATE nodes SET effective_capabilities = advertised_capabilities;

-- Legacy omission and rollback produce the IDENTICAL wire message: a heartbeat
-- with no runtime_contract. This marker is what separates them. NULL => the node
-- has never sent a runtime contract, so omission means a pre-M7.3 donor and the
-- registration snapshot stands. Non-NULL => omission means downgrade, and stale
-- optional-role eligibility must be dropped.
ALTER TABLE nodes ADD COLUMN runtime_contract_observed_at timestamptz;

-- EXPECTED: what the OPERATOR authorized for this node, from a verified lock.
ALTER TABLE nodes ADD COLUMN expected_image_digest       text;
ALTER TABLE nodes ADD COLUMN expected_bundle_lock_digest text;
ALTER TABLE nodes ADD COLUMN expected_at                 timestamptz;
ALTER TABLE nodes ADD COLUMN expected_by                 text;

-- +goose Down
-- (drop in reverse)
```

Legacy `nodes.client_version` is untouched, for old-registration compatibility.
