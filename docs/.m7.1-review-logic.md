## Reviewed and found SOUND (no change)

- **Retention Maintainer gating (`coordinator.go:699-706`).** The Maintainer —
  which now owns partition create-ahead for jobs/audit_log/integrity_audits
  (Task 2) — runs whenever `auditMaintainer != nil` (pool+backend+ks present),
  NOT behind `IntegrityAudit.Enabled`. The scheduler is the only feature-gated
  half. Verified the exact `if` split; a disabled-audits operator still gets
  partitions. MINOR (recorded, not fixed): partition provisioning is coupled to
  `backend != nil && ks != nil`; for a real coordinator both are always present,
  but a cleaner design would provision partitions unconditionally of the audit
  subsystem. Not a beta blocker (migration 0017 also pre-provisions current+2).
- **Empty `source_nebula_addr` (read-source dial safety).** Guarded at BOTH
  layers: the agent advertises `read-source/v1` + `repair-stream/v1` only when
  `SourceNebulaAddr != ""` (agent.go), config validation requires
  `source_read_listen_addr` when it is set, and EVERY selection query
  (possession / replication / storage_state / federation) filters
  `source_nebula_addr IS NOT NULL AND <> ''`. Updates use
  `COALESCE(NULLIF(...,''), existing)` so an empty heartbeat value never wipes a
  stored address. The coordinator can never dial "".
- **Below-floor sweep concurrency (Task 11).** Runs in the single-leader
  orchestrator loop; MarkBelowFloorNodes / ClearBelowFloorNodes / requeue-CTE /
  demote are each ONE atomic statement — no multi-statement transaction, no
  shared mutable Go state. The demote's safety derives from an authority count
  in the same statement (statement-level snapshot), so a concurrent ack/fail
  cannot produce a dip: it can only leave the CID under-target for the next
  tick's normal healing. No new locks needed; no new race surface.
- **`-race` spot check** on bandwidth (token-bucket, genuinely concurrent),
  envelope, and admission packages: clean.
